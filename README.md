# New Digital Marketing.edu

Plataforma de marketing para instituciones educativas (un solo archivo: index.html).

## Publicar en GitHub Pages
1. Crea un repositorio nuevo (por ejemplo: plataforma).
2. Sube index.html, README.md y .nojekyll a la raíz.
3. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
4. En 1-2 minutos estará en https://TU-USUARIO.github.io/plataforma/

## Enlace por institución
Al elegir una institución, la barra de direcciones cambia sola. Copia esa URL y compártela:
- #colegio-demo
- #ndm-institute
- #ucv
- #maria-del-angel
- #catolica-school
- #colegio-la-union
- #virgen-del-carmen

Ejemplo: https://TU-USUARIO.github.io/plataforma/#maria-del-angel

## Acceso de prueba
Admin / Admin (todos los módulos) y Prueba / Prueba (3 módulos, solo lectura).

## Nota
Los datos se guardan solo en el navegador de cada persona (localStorage). Para uso real, conectar una base de datos (por ejemplo Supabase).
La IA del asistente solo funciona dentro de claude.ai; en GitHub Pages responde en modo sin conexión.
