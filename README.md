# New Digital Marketing.edu

Plataforma web de marketing automatizado para instituciones educativas (prototipo de demostración).

Es un solo archivo, `index.html`, sin instalación ni servidor. Los datos son de ejemplo y viven solo en la sesión del navegador.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `new-digital-marketing-edu`).
2. Sube los archivos de esta carpeta a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
6. Espera 1 o 2 minutos. La web quedará en `https://TU-USUARIO.github.io/new-digital-marketing-edu/`.

## Notas

- El inicio de sesión es de demostración: acepta cualquier usuario y contraseña. No subas datos reales de alumnos ni familias.
- La lectura de Excel usa la librería SheetJS desde cdnjs, por lo que se necesita internet.
- Para producción hay que conectar usuarios reales, base de datos, correo y WhatsApp, y cumplir la ley de protección de datos personales del Perú.
